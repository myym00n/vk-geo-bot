# Гео-бот ВК

Android-приложение: бот для беседы ВКонтакте с юмором для геодезистов. Работает прямо на телефоне, без серверов и платных сервисов.

## Что умеет

- **Реакции на слова**: «в работу» / «беру в р», кэф, учтём, Брут, бракодел, геодезические слова, заказчик, зарплата и т.д.
- **Команды**: `/помощь`, `/погода`, `/завтра`, `/выходные`, `/анекдот`, `/брут`, `/бракодел`, `/кэф`, `/кто <текст>`
- **Расписание**: 8:30 погода, 9:00 «Алло, офисные…», 14:00 «пора домой», пятница 17:00
- **Погода** (Open-Meteo, бесплатно, без ключа): сводки и предупреждение о дожде/снеге заранее
- **Анекдоты** с rzhunemogu.ru (можно 18+) + свои геодезические
- Всё редактируется в приложении, есть импорт/экспорт в JSON

## Скачать APK

Вкладка **Releases** справа → последняя «Сборка N» → файл `vk-geo-bot-N.apk`.
Каждый пуш в `main` собирает новую версию автоматически (GitHub Actions). Обновления ставятся поверх, настройки сохраняются.

## Настройка группы ВК (один раз)

1. Создай сообщество (можно закрытое). Его название и аватарка будут именем и аватаркой бота.
2. **Управление → Сообщения** → включить сообщения сообщества.
3. **Управление → Сообщения → Настройки для бота** → включить «Возможности ботов» и «Разрешать добавлять сообщество в беседы».
4. **Управление → Работа с API → Ключи доступа** → «Создать ключ», отметить «Доступ к сообщениям сообщества» (и «управление», если предложит) → скопировать ключ.
5. **Работа с API → Long Poll API** → включить, версия 5.199. Во вкладке «Типы событий» включить **«Входящее сообщение»**.
6. ID группы: в адресе вида `vk.com/club123456789` это число `123456789` (или в «Управление → Основная информация»).

## Настройка приложения

1. Установи APK (разреши установку из неизвестных источников).
2. Вкладка **Настройки** → вставь ключ и ID группы.
3. **Главная** → включи тумблер, разреши уведомления и отключи оптимизацию батареи.
4. Добавь сообщество в беседу: «Добавить участника» → «Сообщества». В настройках беседы дай боту **права администратора**, иначе он видит только сообщения, где его упомянули.
5. Напиши в беседе любое сообщение — бот её запомнит, и туда пойдут сообщения по расписанию.

## Чтобы бот не засыпал

- Батарея → «Без ограничений» для приложения.
- Xiaomi/Huawei/Samsung: разреши автозапуск и закрепи приложение в недавних.
- Телефон на зарядке и с Wi-Fi.
